# Hermes

## Запуск бота

1. Установите зависимости: `python -m pip install -r requirements.txt`.
2. Откройте файл бота на сервере: `nano bot.py`.
3. В начале файла укажите токен от BotFather в строке `BOT_TOKEN = ""`, например
   `BOT_TOKEN = "ваш_токен"`.
4. Сохраните файл в nano (`Ctrl+O`, `Enter`, `Ctrl+X`) и запустите бота:
   `python bot.py`.

Не отправляйте файл `bot.py` с реальным токеном в GitHub.
