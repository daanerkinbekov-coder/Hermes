# Hermes

## Запуск бота

1. Установите зависимости: `python -m pip install -r requirements.txt`.
2. Скопируйте `.env.example` в `.env` и укажите в `.env` токен от BotFather:
   `BOT_TOKEN=ваш_токен`.
3. Запустите бота: `python bot.py`.

Не публикуйте `.env` и не отправляйте его в GitHub. Файл уже добавлен в `.gitignore`.
